BNAN430 - Data Visualization in PowerBI Certificate - (https://public.tableau.com/app/profile/jake.stafford/viz/powerbicertificatew/PowerBIStory?publish=yes) - Sarah,
In the DAX in PowerBI Course, I built the Model view relationships by hand. I dragged FctTripsColumn1 to DimRideType.ride_type_id, but I also saw PowerBI auto-detect relationships when the schema was clean. That contrast is one of the reasons why I would trust automation versus when I check it myself for Southwest's recurring data (daily flight loads, on-time performance). I would let PowerBI build and veryfiy relationships rather than hand-coding the joins in Excel. This is because the model stays live as new data lands. Seperately, in the Data Visualization courtse I used conditional formating on a sales-by-product bar chart, writing a rule that turns any bar below a threshold dark red automatically. That is the capability that matters the most for Anita. Instead of her scanning a static report for underperforming routes or productsm the visual fkags them itself every time it refreshes. 

My division of labor: I would use Excel for any one-off calculations where nobody needs to touch the file again. I would use Tableau when the deliverable is a polished anr presentation ready story for an audience outside the data team.  I would use PowerBI when the data refreshes regularly and more than one person needs to interact with it live (filtering, drilling down, weekly checks). 

My gap: I have only built these reports in DataCamp. I have never publishjed a report to the PowerBI service or kept one running against live company data that other people depend on. That is the next thing that I need hands-on repetition on before I'd call myself ready to own a report at Southwest.
